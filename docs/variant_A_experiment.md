## 1. 实验概述

### 1.1 核心问题

**给生僻字添加部首/拼音信息，能否帮助模型更好地理解和推理汉字？**

这模拟了人类的行为：遇到不认识的字，先看部首猜意思，看声旁猜读音。

### 1.2 实验假设

| 假设ID | 内容 | 预期结果 |
|--------|------|----------|
| H1 | 部首信息能帮助推断语义类别 | 知道"氵"→能说出"与水有关" |
| H2 | 声旁信息能帮助推断读音 | 知道"方"→能联想到读音 |
| H3 | 部首+声旁联合 > 单独信息 | full_enhanced > 其他 |
| H4 | 常见字加注释可能干扰 | 常见字注释可能信息过载 |

### 1.3 实验方法

**类型**: Prompt Engineering（不改变模型）  
**变量**: Prompt中是否包含部首/拼音/声旁信息  
**测试模型**: Claude / GPT-4  
**评价方式**: 人工判断回答质量

## 3. 测试用例详情

### 3.1 典型用例：R1 汸

```
汉字: 汸
拼音: fāng
部首: 氵（三点水）
声旁: 方
本义: 水名

问题: 这个字可能和什么有关？
期望答案: 水、河流、液体相关
```

**5种Prompt对比：**

**baseline:**
```
请回答以下关于汉字的问题：
问题：这个字可能和什么有关？
目标字：汸
```

**pinyin_only:**
```
请回答以下关于汉字的问题：
目标字：汸（读音fāng）
问题：这个字可能和什么有关？
提示：这个字的读音是fāng。
```

**radical_only:**
```
请回答以下关于汉字的问题：
目标字：汸（部首：氵）
问题：这个字可能和什么有关？
提示：这个字的部首是'氵'，在汉字中，部首通常提示字义类别。
```

**full_enhanced:**
```
请回答以下关于汉字的问题：
目标字：汸（部首：氵，声旁：方，读音：fāng）
问题：这个字可能和什么有关？
提示：
1. 部首'氵'通常与水、液体、河流有关
2. 声旁'方'提示读音可能与fāng相近
3. 这是一个形声字，形旁表意，声旁表音
```

**expert_mode:**
```
你是一个汉字学专家。请利用形声字的构字规律回答以下问题。
目标字：汸
结构分析：
- 部首（形旁）：氵 → 表示与水、液体、河流相关
- 声旁（声部）：方 → 提示读音为fāng
问题：这个字可能和什么有关？
```

## 6. 预期发现

### 情景A：部首信息最有效
- radical_only 得分显著高于 pinyin_only
- 说明：对模型而言，"氵=水"的语义关联比声旁读音更容易利用

### 情景B：联合信息有协同效应
- full_enhanced > radical_only 且 full_enhanced > pinyin_only
- 说明：部首和声旁信息互补，同时使用效果更好

### 情景C：专家角色触发推理
- expert_mode 得分最高
- 说明：显式引导模型"像专家一样思考"能激活更好的推理

### 情景D：所有方式无显著差异
- 各条件得分接近
- 可能原因：
  1. 模型已掌握这些汉字知识
  2. 模型无法利用部首/声旁结构信息
  3. Prompt设计不够有效
