- 通义千问

### 2. 准备记录表格

复制以下模板到笔记软件（Notion/Obsidian/Excel）：

```

| R1 | baseline | | /5 | /5 | /5 |
| R1 | radical_only | | /5 | /5 | /5 |
| ... | ... | | | | |
```

**评分标准**:
- **准确性** (0-5): 回答是否正确（是否提到"水"、"火"等）
- **推理质量** (0-5): 是否明确使用了部首/声旁信息
- **总分**: 两项相加

```bash
cd ~/Desktop/token_experiment/variant_A_prompt_enhancement

python3 experiment_runner.py --case R1 --compare

# 方式B：生成特定类别的特定prompt类型
python3 experiment_runner.py --category radical_semantic_inference --prompt-type full_enhanced
```

### 步骤2：复制到模型

1. 打开浏览器，进入 Claude/GPT-4
2. **新开对话**（避免上下文干扰）
3. 复制prompt文本
4. 发送，等待回答

### 步骤3：记录结果

**必须记录**:
- 模型原文回答（可复制粘贴）
- 你的评分（准确性、推理质量）
- 有趣的观察（如：模型自己提到了形声字规律）

**可选记录**:
- 回答长度
- 回答速度/流畅度
- 模型的"信心程度"（确定 vs 猜测）

### 步骤4：换条件重复

**重要**：每次测试都要**新开对话**，避免前面的回答影响后面的判断。

## 最小可行测试（15分钟版）

如果你时间紧张，只做这 **3个测试** 即可验证核心假设：

**测试1**: R1 baseline
```
请回答以下关于汉字的问题：
问题：这个字可能和什么有关？
目标字：汸
```

**测试2**: R1 radical_only
```
请回答以下关于汉字的问题：
目标字：汸（部首：氵）
问题：这个字可能和什么有关？
提示：这个字的部首是'氵'，在汉字中，部首通常提示字义类别。
```

**测试3**: R1 full_enhanced
```
请回答以下关于汉字的问题：
目标字：汸（部首：氵，声旁：方，读音：fāng）
问题：这个字可能和什么有关？
提示：
1. 部首'氵'通常与水、液体、河流有关
2. 声旁'方'提示读音可能与fāng相近
3. 这是一个形声字，形旁表意，声旁表音
```

**对比这3个回答**，就能判断：
- 模型原本知不知道"汸"？
- 部首信息有没有帮助？
- 完整信息是否更好？

## 常见问题

### Q: 模型回答太长，怎么快速判断？

**A**: 关注回答的第一句话，通常包含核心判断。例如：
- ✅ "这个字可能与**水**有关，因为部首是三点水..."
- ❌ "这是一个不常见的字，我无法确定..."
- ❌ "根据我的知识，汸是一个古水名..."（死记硬背，没用部首信息）

### Q: 模型直接说出答案，没有推理过程，怎么评分？

**A**: 准确性可以给分，但推理质量给低分。例如：
- "汸与水有关" → 准确性5，推理质量0（没说为什么）
- "汸的部首是氵，表示与水有关" → 准确性5，推理质量5

### Q: 不同模型回答差异很大，怎么办？

**A**: 这本身就是有趣的发现！记录：
- 哪个模型更善于利用部首信息？
- 哪个模型"知识"更多但"推理"更少？
