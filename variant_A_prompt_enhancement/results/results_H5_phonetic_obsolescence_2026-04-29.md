# H5 系统化验证：声旁失效与模型推断行为

> **测试日期**: 2026-04-29  
> **假设**: H5 — 模型掌握共时形声字规律（非历时），声旁失效时忠实地犯错  
> **测试模型**: Claude Opus 4.7  
> **结论**: H5 需修正，实为 H6 的特例

---

| 字 | 声旁 | 声旁现代读 | 实际读音 | 失效程度 | 先验置信度 |

## 测试结果

### 疲（对照组，声旁有效，置信度 10）

声旁「皮」→ 推断 pí ✅  
**行为**：声旁有效，推断正确，无矛盾

---

### 问/闻/间（声旁严重失效，置信度 10）

声旁「门」读 mén，但三字均读 wèn/wén/jiān。

**Claude 行为**：用记忆纠正声旁推断，明确说出「我知道实际读音，声旁已失效」。

**偏转程度**：0%（记忆主导）

---

### 靛（声旁轻微失效，置信度 7）

声旁「定」读 dìng，靛实际读 diàn（声调偏移）。

**Claude 行为**：推断读音在 dìng/diàn 之间，识别了声调偏移，基本正确。

**偏转程度**：~20%（轻微犯错，但方向对）

---

### 谥（声旁严重失效，置信度 6）

声旁「益」读 yì，谥实际读 shì（古音 yi/shi 相近）。

**Claude 行为**：推断读音接近 yì，同时提到「可能存在古音偏移」，不完全确定。

**偏转程度**：~60%（按声旁犯错，但有保留）

---

### 汭（声旁严重失效，置信度 3）

声旁「内」读 nèi，汭实际读 ruì。

**Claude 行为**：推断读音接近 nèi，完全按声旁，无任何保留。

**偏转程度**：100%（忠实地犯错）

---

## 关键发现：H5 与 H6 的统一

### 原始 H5 表述（需修正）

> ~~模型掌握共时形声字规律，不具备历时演变知识——声旁失效时，会忠实地犯错~~

### 修正后的统一框架

| 条件 | 行为 |
|------|------|
| 声旁有效 + 先验强 | 正确推断（记忆与声旁一致） |
| 声旁失效 + 先验强（问/闻/间） | 用记忆纠正，**不犯错** |
| 声旁失效 + 先验中（谥） | 折中，部分犯错 |
| 声旁失效 + 先验弱（汭） | 忠实按声旁，**完全犯错** |

**核心公式**：

```
是否犯错 = f(声旁失效程度, 先验置信度)

不是「声旁失效 → 必然犯错」
而是「声旁失效 + 先验不足 → 犯错」
```

### H5 并非独立规律，是 H6 的一个表现

H6（先验越低，干扰越大）完全可以解释 H5 的观察结果：
- 「问」的先验是 10，即使声旁失效，也不会被错误声旁带偏
- 「汭」的先验是 3，声旁失效意味着声旁是「错误信息」，自然被完全带偏

两个假设可以合并为**统一推断框架**：

```
推断结果 = 先验知识 × w₁ + 给定信息 × w₂

其中 w₁ + w₂ = 1
w₁ 随先验置信度升高而增大
w₂ 随先验置信度降低而增大

先验 = 10 → w₁ ≈ 1.0, w₂ ≈ 0.0（完全靠记忆）
先验 = 5  → w₁ ≈ w₂ ≈ 0.5（折中）
先验 = 0  → w₁ ≈ 0.0, w₂ ≈ 1.0（完全靠给定信息）
```

---

## 实践意义

### 对 Prompt 增强策略

1. 对先验弱的字（生僻字）：提供正确的声旁 + 读音，模型会完全采用 → **增强效果最大**
2. 对先验强的字（常见字）：提供信息无增益，提供错误信息也无害（会被纠正）→ **无需注释**
3. 声旁失效的字（如汭/谥）：声旁本身是误导性信息，**直接提供正确读音比提供声旁更有效**

### 对模型能力边界的理解

模型对汉字的掌握程度不是二元的（知道/不知道），而是一个连续的置信度分布。Prompt 增强的价值恰好在低置信度区间——这也解释了为什么 Claude 比 GPT-4 更难被增强 prompt 改变：Claude 的平均置信度更高，更多字落在「无需帮助」的区间。
