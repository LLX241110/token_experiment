# Token Experiment：用查字典的方式处理中文输入

> 核心问题：如果用拼音/部首等「字典信息」辅助大模型处理中文，会有什么效果？

**版本**：v0.7 · **最后更新**：2026-05-07

---

## 研究背景

现代大模型使用 BPE（Byte-Pair Encoding）处理中文——它是「盲目的」，不知道「木」和「林」有关系，也不知道「青」在「清/晴/睛」里是表音的声旁。

本项目探索：**把部首、声旁、拼音这些字典结构显式注入 prompt，能否帮模型更好地推理汉字？**

---

## 核心发现

> 完整数据和分析见 [FINDINGS.md](FINDINGS.md)

### H1 · 部首信息帮助语义推断 ✅

给生僻字加部首提示，模型能正确推断语义类别：

```
目标字：汸（部首：氵）
→ 模型推断：与水、河流有关  ✓（实际：水名）

目标字：炇（部首：火）
→ 模型推断：与火、燃烧有关  ✓（实际：火也）
```

### H2 · 声旁信息帮助读音推断 ✅

提供声旁后，读音推断准确率显著提升：

```
目标字：汸（声旁：方）
→ 模型推断：读音接近 fāng  ✓（实际读 fāng）

GPT-4 无提示时：把声旁猜成「丘」→ 推断偏差
GPT-4 有提示时：接受正确声旁「方」→ 推断正确
```

### H3 · 部首 + 声旁联合效果更好 ✅

两种信息互补，联合提供比单独提供效果更稳定：

```
full_enhanced（部首+声旁+拼音）均分：9.8/10
radical_only（只有部首）均分：    7.4/10
pinyin_only（只有拼音）均分：     6.3/10
```

### H4 · 常见字加注释反而有害 ✅

对熟练读者，给常见字标注信息会打断阅读节奏：

```
原句：今天的天气很好
加注：今天(jīntiān)的(de,白勺)天(tiān)气(qì)很(hěn)好(hǎo,女+子)

→ 模型自评：「冗余噪声，增加认知负担，信息过载」
```

最优策略：**只给生僻字注释，常见字留白**。

### H5 · 声旁失效时是否犯错，取决于先验置信度 ✅

声旁失效（古音演变）时，犯不犯错不是固定的——取决于模型对这个字的熟悉程度：

```
问/闻/间（声旁：门 → mén，实际读 wèn/wén/jiān）
→ 常见字，先验强 → 模型用记忆纠正，不犯错  ✓

汭（声旁：内 → nèi，实际读 ruì）
→ 生僻字，先验弱 → 忠实按声旁推断 nèi   ✗
```

H5 是 H6 的特例：先验越弱，越无法识别声旁失效。

### H6 · 先验置信度越低，错误信息干扰越大 ✅

用 7 个氵部字（先验从 10→1）测量相同错误声旁「土」的干扰效果：

```
清  先验10  偏转 0%   → 明确拒绝「土」，维持 qīng
泗  先验8   偏转 0%   → 明确拒绝
洧  先验6   偏转~50%  → 识别冲突，折中推理  ← 临界区
浕  先验4   偏转~80%  → 基本接受「土」
洣  先验2   偏转100%  → 完全按错误信息推断 tǔ
浯  先验1   偏转100%  → 完全按错误信息推断 tǔ
```

**Claude 临界区在置信度 6–7**：超过 7 基本免疫，低于 4 基本沦陷。

统一框架：`推断 = 先验 × w₁ + 给定信息 × w₂`，先验越强 w₁ 越大。

### F6 · 两模型失败模式完全不同（校准差异）✅

同一梯度实验在 gpt-4o-mini 上复刻，发现两模型低先验时的行为模式截然不同：

```
Claude 低先验时：干净地偏向错误声旁读音
  浯 + 错误声旁"土" → 推断读音 tǔ（被带偏，方向明确）

gpt-4o-mini 低先验时：混乱崩塌，产生第三个读音
  浕 + 错误声旁"土" → 推断读音 jiā（既非正确jìn，也非tǔ）
  泗 + 错误声旁"土" → 维持 sì，但说"tǔ与sì相近"（自圆其说）
```

| | Claude | gpt-4o-mini |
|---|---|---|
| 先验弱时偏转 | 干净偏向错误声旁 | 混乱，猜第三个读音 |
| 不确定性表达 | 承认不确定，按给定信息推断 | 仍给出自信答案，但答案错误 |
| 认知风格 | 欠自信（under-confident）| 过自信（over-confident）|

**深层含义**：两模型的**校准程度（calibration）不同**，可能与各自的 RLHF 训练策略有关。

### 变体D额外发现 · 因果关系确立

对不认识的字，故意提供错误的部首或声旁，推断方向精准偏转：

```
字：浯（正确：氵+吾，读wú）

给错误部首「火」→ 推断「与火有关」  （应为水）
给错误声旁「土」→ 推断读音接近 tǔ  （应为wú）

两个维度完全独立，互不影响
→ 证明模型内部存在两条真实的推理通道，不只是查字典
```

### 无 API Key

```bash
cd variant_A_prompt_enhancement

# 生成对比 prompt（复制到 Claude/GPT-4 手动测试）
```

## 变体B 核心结论

| 条件 | 生僻字改善 | 结论 |
|------|-----------|------|
| 小规模（vocab=3000，增强语料） | 7/8 从 2→1 token | 增强语料是**关键因素** |
| 大规模（vocab=30000，baseline） | 7/8 自动改善 | **词表大小是根本因素** |
| 大规模（vocab=30000，增强语料） | 再额外改善 4 个字 | 增强语料是**补充因素** |
| 任何规模（叠加构字：淼/犇） | 无改善 | BPE 的**硬天花板** |
